## 폴더 규칙

- `code/` 실행 스크립트 · `analysis/` 분석 스크립트와 결과 · `runs/` run별 원본
- `_old/` 폐기된 버전 · `_ops/` 캠페인 상태·pid·로그
- `docs/` 실험 준비·결과 보고서 · `sim/` 설계용 페이지 단위 FDP 시뮬레이터
- run 이름: `{단계}_g{N}_{정책}_s{seed}_{번호}`
